## 戦闘解説を追加

戦闘中の操作欄上部「解説」、または上部「遊び方／?」から開けます。交換・敗北画面の「遊び方／?」では直前の戦闘を振り返れます。タイトル・選定中には戦闘の手引きを表示します。

- 戦況：天候と継続、自分・相手の構え、残留、崩し、破勢、軽減膜、絡索、状態、能力段階、実効機動、生得刻印、封印刻、観測済み装具。この相手への全属性の実倍率も表示。
- 術を調べる：味方・相手・術を選び、現在の構えで通常着弾した場合の損傷幅、属性係数、能力・天候・装具・残留反応等の内訳を確認。追加異常が現在の相手に付くか、再装填や奥義覚醒の条件も説明。閲覧は行動予約や乱数を変更しません。
- 直前の理由：実際の着弾ごとの計算値・実減少・直後の耐久、当時の補正と乱数、その処理全体の耐久変化、戦闘の文章を記録。交代、結界・回避・吸収、行動不能、ターン末の毒・天候・パッシブなども参照。記録は戦闘ごとに直近36件、各記録10着弾・24文章まで。
- 相性表：81組の実倍率。複合属性は基礎値を合成してから倍率を整えるため、現在の相手を調べると最も正確です。
- 手引き：基本、行動順・交代、構え・10種の残留反応、状態異常、全10異変と運命の確率、覚醒・パッシブ・双獣試闘。長い解説はダイアログ内部だけをスクロールできます。

予測は通常着弾1発の幅です。綻び・超会心・踏みとどまり・行動前の状況変化を保証せず、混沌の術は固定損傷を予測しません。2対2の解説で味方・相手を変えても、実際の予約・標的・戦場フォーカスは変更しません。相手の未観測装具は伏せたまま。放置モードは解説中に次の判断を待ちます（既に始まっている演出は続きます）。

難易度・属性係数・戦闘の乱数・損傷式は保持。迎撃の「遠隔は被損傷5%増」という既存挙動を説明に明記しました。`test/guide-engine-results.json` で変更前の損傷600ケースと乱数不変・記録上限、`test/guide-results.json` で7画面サイズ×5タブ、実損傷の照合、双獣・敗北後の閲覧を確認できます。

## 追加した読み合い

### 構え

毎ターン、技を選ぶ前に構えを指定します。

- **踏込**：与える損傷+12%、受ける損傷+12%。
- **迎撃**：接触攻撃を25%軽減。接触を受けると相手の崩しを進め、覚醒も得ます。遠隔攻撃には弱くなります。
- **纏装**：魔法を18%軽減。物理の損傷は8%増。反応を起こすと覚醒を追加で得ます。

相手はプレイヤーの入力前に行動を決定します。近接・遠隔・変化・交代・奥義の兆候を表示します。アビス・アイは、相手の技を2つ確認すると次の技まで観測できます。

### 残留反応

命中した属性は2ターン相手に残ります。残留と次の属性が組み合わさると、損傷だけでなく減速、吸収、浄化、崩しなどの反応が起きます。

例：燼→水「蒸裂」、濡れ→雷「導雷」、霜→鋼「砕氷」、影→聖「祓影」。発生する反応は技ボタンに表示されます。交代で残留は消えます。

固定相性は保持しつつ倍率を緩め、構え・残留・パッシブの組み合わせが重要になるよう調整しています。

### 崩しと封印刻

接触・連撃・属性反応で崩しを蓄積。3で「破勢」となり、次ターンまで被ダメージが20%増えます。交代で立て直せます。

基本特性31種に加え、魔獣30体それぞれへ**封印刻**を追加しました。構えの切り替え、反応、交代、蓄電、反撃、控えの回復などに連動します。カードの「詳細 → 封印刻」または戦闘中の「封印刻」で説明を確認できます。

## 起動

VALGA.html は画像・音・ライブラリ内蔵。ブラウザーで開いてください。フォルダー版は `node serve.cjs 8142` で起動します。

画像は最大512px WebP、効果音は32kHzモノラルMP3に最適化。生成原本は `art-direction/` に保持。提供BGM10曲、効果音186パターンを収録しています。最新フォルダー配布版は親フォルダーの `atelier-release/`。

PC Chromeでの画面・ロジック検証を実施。スマホ実機・iOS Safariは未検証です。
