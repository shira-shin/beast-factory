# 契約具と、契約の痕跡

内蔵 `image_gen` で21枚の原本を新規生成しました。外部CLI/APIは使っていません。

- 契約具14種：各アイテムIDの透過PNG。配布用は `../../assets/items/*.webp`。
- 召喚の裂け目・出現撤退の霧・防護・修復・破勢：各8枚、計40フレームを含む5枚のアトラス。
- 状態アイコン8種：states-atlas.png。
- 戦場アイコン10種：fields-atlas.png。
- 使用した全21本のプロンプト：prompts.json。
- 一覧と演出プレビュー：gallery.html。contact-sheet.pngは確認用の静止画。

PNG原本はソース版のこのフォルダーに保持しています。軽量な配布版には最適化したWebP・PNGアトラスと、一覧・プロンプトを収録しています。

## ゲームへの反映

召喚時の札と足元の常設魔法陣を廃止しました。裂け目が開き、身体を原寸のまま霧から段階的に見せ、交代時は同じ裂け目へ退きます。召喚中は操作ドックを隠し、入力できる時点で表示します。2対2でも未召喚の個体は表示しません。

連番は隣り合う2フレームを補間して再生。身体の出現マスクと演出用スプライトは終了時に片付けます。演出控えめではアトラスの静止フレームとフェードを使用します。

契約具画像は選定・交換・詳細・戦闘中の装備表示へ接続。戦闘中の「装具」で現在の装備を確認でき、「設定 → 契約具図鑑」から全14種を見られます。消費済みの装具は薄く表示。身代わり、果実回復、宝珠の反動、吸収、棘の反撃、ターン終了時の回復などの実際の発動に画像を添えています。装具の効果・数値は変更していません。

防護・回復・破勢・状態と戦場表示にも生成素材を反映しています。既存30体、属性反応、再装填、パッシブ、連戦、1対1・2対2、提供BGM5曲は保持しています。
